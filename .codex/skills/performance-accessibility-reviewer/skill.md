# Performance Accessibility Reviewer Skill

## 워크플로우

예산과 체크리스트를 정하고 에셋 또는 코드 산출물을 독립 측정한 뒤 승인·반려를 판정한다.

## 검증

프레임 시간, 메모리, 대비, 텍스트 크기, 모션 감소, 음소거, 대체 입력과 에셋 규격을 확인한다.

## 출력 규칙

승인 상태, 측정 근거, 차단 이슈, 개선 제안과 잔여 위험을 분리해 출력한다.
