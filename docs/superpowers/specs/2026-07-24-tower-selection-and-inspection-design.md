# 타워 선택 취소 및 설치 타워 정보 조회 설계

## 배경

현재 타워 버튼은 보유 골드가 건설 비용보다 적으면 비활성화된다. 이미 선택한
타워를 배치해 골드가 부족해진 경우에도 같은 규칙이 적용되므로, 사용자는 선택된
버튼을 다시 눌러 배치 모드를 취소할 수 없다.

또한 캔버스 입력은 배치할 타워가 선택된 경우에만 처리한다. 배치 모드를 취소한
뒤 설치된 타워를 눌러도 아무 반응이 없어 이름, 공격력 또는 사정거리를 확인할 수
없다.

## 목표

- 선택 중인 타워는 골드가 부족해져도 다시 눌러 배치 모드를 취소할 수 있다.
- 배치 모드가 아닐 때 설치된 타워를 누르면 해당 타워의 정보를 확인할 수 있다.
- 정보 패널은 전투 화면과 몬스터 이동 경로를 최대한 가리지 않는다.
- 사정거리는 텍스트가 아니라 기존 맵 범위 가이드로만 표시한다.
- 타워 밸런스 수치는 `TOWER_CATALOG`를 단일 기준으로 사용한다.

## 범위에서 제외하는 항목

- 타워 판매, 철거, 업그레이드 기능
- 공격 대상 지정 또는 우선순위 변경
- 공격 간격과 폭발 범위의 텍스트 표시
- 사정거리 수치의 텍스트 표시
- 새로운 게임 저장 데이터 또는 환경설정 마이그레이션

## 상호작용

### 골드 부족 상태에서 선택 취소

- 전투가 진행 중이고 화면 방향 제한이 없을 때만 타워 버튼을 조작할 수 있다는
  기존 규칙을 유지한다.
- 선택되지 않은 타워는 골드가 부족하면 기존처럼 비활성화한다.
- 현재 선택된 타워만 골드 부족 예외를 적용해 활성 상태를 유지한다.
- 선택된 버튼을 다시 누르면 `selectedTower`와 배치 미리보기 셀을 모두 해제한다.
- 골드가 부족한 타워를 새로 선택하는 동작은 허용하지 않는다.

### 설치 타워 조회

- 배치 모드가 아닐 때 캔버스의 설치된 타워를 탭하면 해당 타워를 조회 상태로
  선택한다.
- 다른 설치 타워를 탭하면 조회 대상을 교체한다.
- 빈 타일, 그리드 바깥 또는 정보 패널의 닫기 버튼을 누르면 조회 상태를 해제한다.
- 일시정지 상태에서도 설치된 타워를 조회할 수 있다.
- 배치용 타워를 선택하면 기존 조회 상태를 즉시 해제한다.
- 새 게임 시작, 승리 또는 패배 진입 시 조회 상태를 해제한다.
- 조회 중에는 배치 가능 영역과 미리보기 타워를 표시하지 않는다.

## 상태와 데이터 흐름

`GameRuntimeSnapshot`에 `inspectedTowerId: number | null`을 추가한다.
`GameRuntime`은 `inspectTower(id: number | null)` 명령을 제공한다.

- `startGame()`과 게임 결과 확정은 조회 상태를 `null`로 초기화한다.
- `selectTower(type)`에 실제 타워 유형이 전달되면 조회 상태를 해제한다.
- `inspectTower(id)`는 배치 타워와 배치 셀을 해제한 상태에서 조회 대상을 갱신한다.
- 렌더링 시 현재 게임의 `towers`에서 ID를 다시 조회한다. ID가 없으면 패널과 범위
  가이드를 표시하지 않는다.

캔버스 탭은 다음 순서로 처리한다.

1. 배치 타워가 선택돼 있으면 기존 배치 미리보기 흐름을 실행한다.
2. 배치 타워가 없고 게임이 진행 또는 일시정지 상태이면 탭 좌표를 셀로 변환한다.
3. 해당 셀의 설치 타워를 찾아 `inspectTower(tower.id)`를 호출한다.
4. 설치 타워가 없거나 셀 변환에 실패하면 `inspectTower(null)`을 호출한다.

## 맵 표현

설치 타워 조회에도 기존 `drawMap` 선택·사정거리 표현을 재사용한다.

- 선택 셀: 설치 타워의 `cell`
- 사정거리: `TOWER_CATALOG[tower.type].range`
- 선택 유효성: 항상 유효
- 배치 가능 영역: 미표시
- 미리보기 타워: 미표시

따라서 배치 가이드와 동일한 원근 투영을 유지하면서 사정거리 숫자는 HUD에
중복 표시하지 않는다.

## 정보 패널

게임 스테이지 안에 `설치 타워 정보` 영역을 추가한다.

- 기본 타워 트레이가 아래에 있으면 패널은 트레이 바로 위에 표시한다.
- 모바일에서 트레이를 위로 옮기면 패널은 트레이 바로 아래에 표시한다.
- 한 줄 반투명 패널로 구성해 맵 중앙 점유를 최소화한다.
- 닫기 버튼은 최소 `44 × 44px` 터치 영역을 보장한다.
- 패널은 조회 대상이 없으면 DOM에서 숨긴다.

표시 내용은 다음으로 제한한다.

| 타워 | 표시 |
| --- | --- |
| 슬로우 타워 | `슬로우 타워 · 둔화 38%` |
| 화살 타워 | `화살 타워 · 공격력 18` |
| 덕배 | `덕배 · 공격력 14` |
| 후추 | `후추 · 공격력 72` |

이름은 기존 `TOWER_CARDS`, 공격력과 둔화율은 `TOWER_CATALOG`에서 계산한다.
슬로우 타워의 둔화율은 `(1 - multiplier) × 100`을 반올림한다. 사정거리,
공격 간격과 폭발 범위는 패널에 표시하지 않는다.

## 접근성

- 패널은 `aria-label="설치 타워 정보"`를 갖는 명시적인 영역으로 제공한다.
- 닫기 버튼은 `aria-label="<타워 이름> 정보 닫기"`를 제공한다.
- 타워 버튼은 현재 선택 여부를 기존 `aria-pressed`로 유지한다.
- 골드 부족 상태에서도 선택된 버튼만 조작 가능하며, 다른 구매 불가능 버튼의
  `disabled` 의미는 유지한다.

## 오류 및 경계 처리

- 존재하지 않는 타워 ID는 조회하지 않은 상태와 동일하게 처리한다.
- 잘못된 공격력 또는 둔화 수치는 화면에 `0`으로 정규화한다.
- 결과 화면, 준비 화면, 세로 방향 차단 화면에서는 캔버스 조회를 시작하지 않는다.
- 일시정지 중 배치 모드는 새로 시작할 수 없지만, 이미 설치된 타워 정보 조회는
  허용한다.

## 테스트와 검증

### 단위 테스트

- 골드가 부족해도 현재 선택된 타워 버튼만 활성 상태를 유지한다.
- 선택되지 않은 구매 불가능 타워 버튼은 계속 비활성화된다.
- 런타임이 조회 ID를 설정, 교체, 초기화한다.
- 배치 타워 선택과 새 게임 시작 및 결과 확정이 조회 상태를 해제한다.
- 타워 정보 뷰가 이름과 공격력 또는 둔화율만 생성한다.
- 패널 표시와 닫기 접근성 속성을 검증한다.
- 조회 상태가 기존 맵 선택 셀과 사정거리 렌더 입력으로 전달된다.

### 통합 검증

- `npm run check`로 전체 Vitest 테스트, TypeScript 검사와 프로덕션 빌드를 실행한다.
- 모바일 가로 화면에서 다음을 브라우저 스모크 테스트한다.
  - 골드가 부족한 선택 타워를 다시 눌러 취소
  - 설치된 타워 선택 시 패널과 맵 사정거리 표시
  - 빈 타일 및 닫기 버튼으로 패널 종료
  - 위·아래 타워 트레이 위치에서 패널이 중앙 전투 영역을 가리지 않는지 확인
- 별도의 전체 E2E 스위트는 실행하지 않는다.

## 완료 조건

- 골드 부족으로 선택 취소가 막히는 경로가 없다.
- 설치된 네 종류 타워 모두 정확한 이름과 주 능력치를 표시한다.
- 사정거리는 맵에서만 표시되고 패널에는 숫자로 노출되지 않는다.
- 빈 타일과 닫기 버튼이 정보 패널과 범위 가이드를 함께 닫는다.
- 기존 배치 확인·취소, 타워 트레이 위치 전환과 모바일 터치 영역이 회귀하지 않는다.
