# 정사각형 타일과 정면형 랜드마크 설계

## 목표

- 20×10 스테이지와 기존 경로·난이도를 유지한다.
- 가로형 화면에서 각 타일이 중앙 깊이 기준 1:1로 보이게 한다.
- 원근감은 유지하되 위쪽과 아래쪽 타일의 왜곡을 약 ±10%로 제한한다.
- 시작점 구조물을 화면에서 완전히 제거한다.
- 보물상자를 바닥판이 없는 정면형 3D 에셋으로 다시 렌더링한다.
- 투영 변경 뒤에도 터치 좌표, 타워 배치, 유닛 크기와 바닥 고정이 같은 좌표계를 사용한다.

## 범위

### 포함

- 캔버스 맵 투영과 레이아웃 계산
- 시작점·보물상자 렌더링
- Blender 기반 보물상자 에셋 재렌더링
- 투영, 맵 렌더링, 에셋 계약 및 모바일 E2E 회귀 테스트
- 844×390 QA 스크린샷 갱신

### 제외

- 경로, 웨이브, 타워 비용과 공격 수치 변경
- 맵의 행 또는 열 삭제
- 새로운 타워·적·스테이지 추가
- 시작점에 대한 대체 아이콘이나 장식 추가

## 투영 설계

현재 레이아웃은 맵 너비와 높이를 독립적으로 정해 화면 비율에 따라 타일이 가로로 길어지거나 세로로 길어진다. 새 레이아웃은 하나의 기준 셀 너비에서 가로와 세로 간격을 함께 계산한다.

1. 원근 배율은 위쪽 `0.88`, 아래쪽 `1.05`를 사용한다.
2. 중앙 깊이 배율은 두 값의 중간인 `0.965`다.
3. 사용 가능한 너비와 높이에서 각각 허용되는 기준 셀 너비를 계산한다.
4. 두 값 중 작은 값을 실제 기준 셀 너비로 선택해 보드가 잘리지 않게 한다.
5. 행 간격은 `기준 셀 너비 × 0.965`로 계산한다.

따라서 중앙 타일은 정확히 1:1이고, 위쪽 타일의 가로/세로 비는 약 `0.912`, 아래쪽은 약 `1.088`이 된다. 화면이 매우 넓거나 낮아도 보드를 확대해 자르지 않고 중앙 정렬한다.

맵의 최대 사용 영역은 캔버스 너비의 96%, 높이의 90%다. 실제 `mapArea`는 투영 결과로 산출한 보드 외곽 크기를 기록하며, 터치 역투영도 동일한 값을 사용한다.

## 시작점과 보물상자

### 시작점

- `entry.png`는 기존 에셋 계약 보존을 위해 파일과 manifest에 남겨 둔다.
- 게임 렌더러에서는 시작점 에셋을 호출하지 않는다.
- 첫 번째 경로 셀은 다른 경로 셀과 같은 단색 모래 타일로만 보인다.
- 적은 현재와 동일하게 첫 경로 셀에서 생성된다.

### 보물상자

- Blender 생성기의 `build_snack_chest()`에서 타일 베이스를 제거한다.
- 상자 전면이 공통 카메라를 향하도록 Z축 방향을 보정한다.
- PNG 배경은 투명하게 유지한다.
- 간식과 금색 잠금장치가 정면에서 식별 가능해야 한다.
- 렌더러는 마지막 경로 셀의 앞쪽 바닥선에 상자를 고정한다.
- 크기와 깊이 배율은 적·타워와 동일한 투영 기준을 사용한다.

## 렌더링과 입력 흐름

1. `computeCanvasLayout()`가 기준 셀 너비, 행 간격, 실제 맵 영역을 계산한다.
2. `projectWorldPoint()`와 `unprojectScreenPoint()`가 같은 원근 배율과 행 간격을 사용한다.
3. 맵, 선택 범위, 타워, 적, 투사체와 보물상자가 모두 공유 투영을 사용한다.
4. 시작점 스프라이트는 그리지 않는다.
5. 보물상자는 마지막 경로 셀에 그린 뒤 유닛의 화면 Y 기반 깊이 정렬 규칙과 시각적으로 일치하게 바닥에 고정한다.

## 오류와 경계 조건

- 0 이하 또는 비정상 viewport 값은 기존처럼 최소 1픽셀로 정규화한다.
- 세로 화면에서는 기존 방향 전환 안내를 유지한다.
- 매우 낮은 가로 화면에서는 정사각형 비율을 우선하며 맵 좌우에 여백을 허용한다.
- 보물상자 PNG 로딩에 실패하면 기존 로더 정책대로 게임은 계속 실행하고 해당 스프라이트만 생략한다.
- 시작점 에셋 로딩 여부는 게임 진행에 영향을 주지 않는다.

## 테스트와 승인 기준

### 단위 테스트

- 844×390 및 1280×720 레이아웃에서 보드가 캔버스 안에 들어온다.
- 중앙 깊이 타일의 가로/세로 비율이 1에 가깝다.
- 위쪽과 아래쪽 타일의 가로/세로 비율이 각각 0.90~1.10 범위에 들어온다.
- 투영 후 역투영한 좌표가 기존 허용 오차 안에서 복원된다.
- 맵 렌더링 호출에 `map-entry`가 없고 `map-snack-chest`는 존재한다.
- Blender 에셋 계약은 보물상자에 타일 베이스가 없고 정면 방향 보정이 있음을 검증한다.

### 통합·시각 테스트

- `npm run check`가 전체 통과한다.
- 844×390 E2E에서 게임 시작, 타워 선택, 배치 미리보기와 확정이 동작한다.
- 갱신된 QA 스크린샷에서 시작점 구조물이 보이지 않는다.
- 보물상자는 배경판 없이 정면을 보고 마지막 경로 셀 바닥에 닿아 있다.
- 타워와 적이 기존처럼 정확한 셀 위에 있고 터치 위치가 어긋나지 않는다.
