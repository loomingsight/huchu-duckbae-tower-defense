# 흡혈 박쥐 둔화 저항 안내 설계

## 목적

흡혈 박쥐에 슬로우 타워가 처음 영향을 줄 때, 플레이를 멈추지 않고 둔화 저항 규칙을 설명한다. 현재 청록색 `+` 표시는 회복 효과로 오해될 수 있으므로 제거하고, 둔화가 일부 저항됐다는 의미가 직접 드러나는 시각 언어로 교체한다.

## 범위

- 흡혈 박쥐의 둔화 저항이 한 번의 게임 도전에서 처음 발동할 때 안내한다.
- 안내 중에도 시뮬레이션, 입력과 게임 시간이 계속 진행된다.
- 별도의 도감, 영구 저장 상태와 다시 보기 화면은 이번 범위에 포함하지 않는다.
- 해골 기사의 방패 효과와 흡혈 박쥐의 둔화 저항 효과를 시각적으로 분리한다.

## 발동 규칙

1. `slow-resist` 특성 이벤트가 발생하면 현재 도전에서 안내를 표시했는지 확인한다.
2. 아직 표시하지 않았다면 안내를 시작하고 현재 도전에서 표시 완료로 기록한다.
3. 같은 도전에서 이어지는 `slow-resist` 이벤트는 시각 효과만 재생하고 안내를 반복하지 않는다.
4. 재도전을 시작하면 표시 상태를 초기화한다.
5. 둔화가 실제로 적용되지 않은 단순 등장 시점에는 안내하지 않는다.

표시 상태는 실행 중 boolean 하나로만 관리한다. `localStorage`와 환경설정 스키마는 변경하지 않는다.

## 비차단 안내

- 위치: 모바일 가로 화면의 게임 영역 상단 중앙
- 표시 시간: 2.5초
- 입력: `pointer-events: none`; 타워 선택과 배치를 가리지 않는다.
- 제목: `흡혈 박쥐 · 둔화 저항`
- 설명: `슬로우 효과가 50%만 적용돼요`
- 진입과 퇴장: 짧은 투명도 전환만 사용한다.
- 여러 특성 안내가 동시에 필요해져도 이번 구현에서는 흡혈 박쥐 안내 하나만 다룬다.

## 전투 시각 효과

- 대상: 둔화 저항이 발동한 흡혈 박쥐
- 보라색 날개 섬광을 짧게 표시한다.
- 박쥐 주위의 청색 얼음 고리가 두 조각으로 끊어지는 효과를 표시한다.
- 회복으로 읽히는 청록색 `+` 표시는 사용하지 않는다.
- 방패 모양은 사용하지 않는다. 반투명 가상 방패는 해골 기사 전용이다.
- 효과는 기존 `slow-resist` 이벤트 제한 주기인 0.8초를 그대로 따른다.

## 접근성과 모션 감소

- 배너 텍스트는 `aria-live="polite"`로 한 번 안내한다.
- 배너의 텍스트 대비는 기존 다크 HUD 기준을 만족시킨다.
- `prefers-reduced-motion: reduce`에서는 날개 섬광의 이동·확산을 줄인다.
- 모션 감소 상태에서도 배너와 끊어진 청색 고리는 유지해 전투 규칙을 식별할 수 있게 한다.

## 구성 경계

- 시뮬레이션은 기존 `slow-resist` 이벤트만 발행하며 UI 표시 여부를 알지 못한다.
- `GameApp`의 프레임 이벤트 처리기가 최초 이벤트 여부와 2.5초 수명을 관리한다.
- HUD는 전달받은 안내 뷰를 렌더링할 뿐 게임 상태를 변경하지 않는다.
- Canvas 효과는 기존 `slow-resist` `RuntimeEffect`를 사용하고 배너 DOM과 독립적으로 재생한다.

## 검증

- 첫 `slow-resist` 이벤트에서 배너가 표시된다.
- 같은 도전의 후속 이벤트에서는 배너가 반복되지 않는다.
- 재도전 후 첫 이벤트에서는 다시 표시된다.
- 배너 표시 중에도 게임이 일시정지되지 않는다.
- 배너가 2.5초 후 사라진다.
- `slow-resist` Canvas 효과에 방패나 `+` 기호가 포함되지 않는다.
- 모션 감소 상태에서도 설명과 끊어진 고리가 남는다.
- 기존 단위 테스트와 프로덕션 빌드가 통과한다.
- E2E 테스트는 사용자가 제외했으므로 실행하지 않는다.

## 승인된 결정

- 전투를 계속 진행하는 비차단 안내를 사용한다.
- 표시 주기는 한 번의 게임 도전당 최초 1회다.
- 영구 저장과 도감은 추가하지 않는다.
- 둔화 저항은 보라색 날개 섬광과 깨진 청색 얼음 고리로 표현한다.
