# 나이트메어 초반 그림자 슬라임 재조정 설계

- 작성일: 2026-07-24
- 대상 저장소: `huchu-defense-v2`
- 상태: 대화 설계 승인 완료, 문서 검토 후 구현
- 배포 대상: `main` → GitHub Pages

## 1. 배경

그림자 슬라임은 본체가 죽으면 체력 25%의 자식 두 마리로 한 번 분열한다.
현재 N1 첫 웨이브는 본체 10마리가 최대 30개체로 늘어나며, 그림자 슬라임
가중치가 높은 N4 첫 웨이브는 본체 14마리가 최대 42개체가 된다.

N1 첫 웨이브의 자식만 화살 한 발에 처치할 수 있고, N2부터는 스테이지 HP
배율 때문에 대부분 두 발이 필요하다. 이 조합은 모든 나이트메어 스테이지의
초반 3웨이브에서 타워 구성이 성장하기 전에 과도한 수량 압박을 만든다.

## 2. 확정된 사용자 결정

| 항목 | 결정 |
| --- | --- |
| 적용 스테이지 | N1~N6 전체 |
| 적용 구간 | 각 스테이지의 1~3웨이브 |
| 분열 방식 | 본체 1마리에서 자식 2마리, 재분열 없음 |
| 수량 | 초반 그림자 슬라임 본체 약 33~43% 감소 |
| 자식 HP | 부모 최대 HP의 25%에서 17%로 감소 |
| 경제 | 줄어든 개체 수만큼 초반 골드 수입 보전 |
| 점수 | 줄어든 개체 수만큼 초반 전투 점수 보전 |
| 후반 | 4~10웨이브 수량·보상·간격 유지 |
| 검증 | 단위 테스트·타입 검사·프로덕션 빌드 |
| 제외 | 전체 E2E와 시각 에셋 변경 |

## 3. 목표

1. 모든 나이트메어 스테이지의 첫 세 웨이브를 안정적으로 넘길 수 있게 한다.
2. 분열 슬라임의 정체성인 `1 → 2` 분열은 유지한다.
3. 초반 수량을 줄여 화면 혼잡과 순간 타격 요구량을 낮춘다.
4. 감소한 적 수 때문에 타워 성장이나 별점 획득이 더 어려워지지 않게 한다.
5. 4웨이브 이후의 기존 난도 상승과 스테이지별 차이는 보존한다.

## 4. 비목표

- 그림자 슬라임 본체 HP, 이동 속도, 누수 피해는 변경하지 않는다.
- 자식의 수, 이동 속도, 보상, 점수, 누수 피해와 재분열 규칙은 변경하지 않는다.
- 박쥐, 해골 기사, 흑요석 골렘과 리치 왕의 수치·특성은 변경하지 않는다.
- 나이트메어 시작 골드, 타워 가격, 별점 기준과 스테이지 난도 배율은 변경하지
  않는다.
- 맵, UI, 애니메이션, 이미지와 오디오는 변경하지 않는다.

## 5. 웨이브 수량 계약

`src/game/waves/nightmareWaves.ts`의 공통 베이스 수량 중 첫 세 웨이브의
그림자 슬라임 열만 `10/8/6`에서 `6/5/4`로 바꾼다. 기존 스테이지별
`TYPE_WEIGHTS`와 `countMultiplier`를 적용한 최종 수량은 다음과 같다.

| 스테이지 | 현재 1~3웨이브 | 변경 후 1~3웨이브 | 감소율 |
| --- | ---: | ---: | ---: |
| N1 | 10 / 8 / 6 | 6 / 5 / 4 | 37.5% |
| N2 | 9 / 7 / 5 | 5 / 5 / 4 | 33.3% |
| N3 | 9 / 7 / 5 | 5 / 4 / 3 | 42.9% |
| N4 | 14 / 11 / 8 | 8 / 7 / 5 | 39.4% |
| N5 | 9 / 7 / 5 | 5 / 4 / 3 | 42.9% |
| N6 | 12 / 9 / 7 | 7 / 6 / 5 | 35.7% |

4~10웨이브의 `BASE_COUNTS`, 모든 박쥐·해골 기사·골렘 수량, 스폰 간격,
엘리트와 보스 구성은 그대로 둔다.

## 6. 분열체 체력 계약

`src/game/simulation/updateEnemies.ts`의 자식 HP 비율을 다음처럼 바꾼다.

```ts
const SHADOW_SLIME_CHILD_HP_RATIO = 0.17;
```

본체 HP에는 기존 스테이지·웨이브 배율이 한 번만 적용된다. 자식은 그 결과인
부모 최대 HP의 17%로 생성된다. N1~N4의 초반 자식은 공격력 18인 화살 한
발에 처치되고, N5~N6은 스테이지와 웨이브 배율에 따라 한 발에서 두 발로
자연스럽게 상승한다.

분열은 부모 `splitGeneration === 0`일 때만 발생하며 자식은
`splitGeneration: 1`을 유지한다.

## 7. 골드와 전투 점수 보전

수량만 줄이면 초반 골드와 나이트메어 전투 점수가 함께 감소한다. 이를 막기
위해 `WaveGroup`에 선택적 `killValueMultiplier`를 추가한다.

```ts
type WaveGroup = Readonly<{
  type: EnemyType;
  count: number;
  spawnInterval: number;
  variant?: EnemyVariant;
  killValueMultiplier?: number;
}>;
```

나이트메어 1~3웨이브의 그림자 슬라임 부모 그룹에만
`killValueMultiplier: 2`를 지정한다. `spawnEnemy`는 이 값을 부모의 골드
보상과 `combatScore`에 한 번만 적용한다. 자식 값은 기존 수치를 유지한다.

| 항목 | 현재 가족 전체 | 변경 후 가족 전체 |
| --- | ---: | ---: |
| 골드 | 부모 3G + 자식 2G×2 = 7G | 부모 7G + 자식 2G×2 = 11G |
| 전투 점수 | 부모 15 + 자식 5×2 = 25 | 부모 30 + 자식 5×2 = 40 |

초반 세 웨이브의 그림자 슬라임 총 골드는 다음 범위에 남는다.

| 스테이지 | 현재 | 변경 후 | 편차 |
| --- | ---: | ---: | ---: |
| N1 | 168G | 165G | -2% |
| N2 | 147G | 154G | +5% |
| N3 | 147G | 132G | -10% |
| N4 | 231G | 220G | -5% |
| N5 | 147G | 132G | -10% |
| N6 | 196G | 198G | +1% |

전투 점수도 같은 배율 구조로 현재 대비 약 ±10% 안에 유지되므로 기존 별점
기준을 변경하지 않는다.

## 8. 데이터 흐름과 유효성

1. `createNightmareWaves`가 수량과 초반 `killValueMultiplier`를 선언한다.
2. `updateWaves`가 그룹 값을 `spawnEnemy`에 전달한다.
3. `spawnEnemy`가 부모의 보상과 전투 점수에 배율을 적용한다.
4. 부모 처치 시 `updateEnemies`가 체력 17%의 자식 두 마리를 만든다.
5. 자식 처치 시 기존 자식 보상·점수를 지급하고 더 분열하지 않는다.

`killValueMultiplier`가 생략되면 1을 사용한다. 값이 존재할 때는 유한한
양수여야 하며, 0·음수·`NaN`·무한대는 `isValidWaveGroup`에서 거부한다.
이로써 잘못된 웨이브가 무한 스폰이나 비정상 골드·점수를 만들지 않게 한다.

## 9. 테스트 전략

### 9.1 웨이브

- N1~N6의 1~3웨이브 그림자 슬라임 최종 수량을 표와 대조한다.
- 해당 그룹에만 `killValueMultiplier: 2`가 있는지 검증한다.
- 4~10웨이브 수량과 배율이 현재 값과 같은지 검증한다.
- 잘못된 `killValueMultiplier`를 가진 그룹을 거부하는지 검증한다.

### 9.2 분열·경제·점수

- 부모 한 마리가 정확히 자식 두 마리로 한 번만 분열하는지 검증한다.
- 자식 최대 HP가 부모 최대 HP의 17%인지 검증한다.
- N1~N4 초반 자식이 화살 한 발에 처치되는지 검증한다.
- N5~N6에서 승인된 HP 상승 곡선이 유지되는지 검증한다.
- 초반 가족 보상이 11G, 전투 점수가 40인지 검증한다.
- 4웨이브 이후 가족 보상 7G와 전투 점수 25가 유지되는지 검증한다.
- N1~N6 초반 총 골드와 점수가 현재 대비 ±10% 범위인지 검증한다.

### 9.3 통합 검증

- 집중 Vitest 실행
- `npm run check`
- `dist/index.html`의 JS/CSS 경로가
  `/huchu-duckbae-tower-defense/`로 시작하는지 확인
- 전체 E2E는 밸런스 수치 변경 정책에 따라 실행하지 않음

## 11. 완료 기준

- N1~N6의 첫 세 웨이브 그림자 슬라임 수가 승인 표와 일치한다.
- 그림자 슬라임은 본체 1마리에서 자식 2마리로 한 번만 분열한다.
- 자식 HP는 부모 최대 HP의 17%다.
- 초반 그림자 슬라임 골드와 전투 점수가 기존 대비 약 ±10% 안에 유지된다.
- 4웨이브 이후 난도·보상·점수와 다른 적의 수치는 바뀌지 않는다.
- 관련 단위 테스트, 전체 단위 테스트, 타입 검사와 프로덕션 빌드가 통과한다.
