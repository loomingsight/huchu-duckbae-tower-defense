## 6스테이지 확장

> 설계서: [6스테이지 진행 및 난이도 설계](./superpowers/specs/2026-07-21-six-stage-progression-design.md)
>
> 리소스 절약을 위해 신규 에셋과 E2E는 제외하고 단위 테스트·타입 검사·프로덕션 빌드로 검증한다.

- [x] 공통 맵 팩토리와 데이터 기반 `STAGE_CATALOG` 구성
- [x] 기존 맵을 포함한 직각 단일 경로 맵 6개 적용
- [x] 스테이지별 10웨이브 적 조합과 HP·속도·스폰 간격 난이도 배율 적용
- [x] 시뮬레이션·배치·타게팅·렌더링을 현재 `stageId` 기준으로 연결
- [x] 매 스테이지 시작 시 타워·골드·창고 내구도 초기화
- [x] 기존 오버레이에 1~6 스테이지 선택과 순차 해금·다음 스테이지 동작 추가
- [x] preferences v3 이전과 스테이지별 최고 점수·최단 시간 저장
- [x] 전체 단위 테스트·타입 검사·프로덕션 빌드 검증 및 E2E 미실행 명시
