## 게임 밸런스

> 난이도 수치 조정이므로 E2E는 제외하고 단위 테스트와 프로덕션 빌드로 검증한다.
>
> 후속 설계서: [나이트메어 초반 그림자 슬라임 재조정 설계](./superpowers/specs/2026-07-24-nightmare-early-wave-rebalance-design.md)
>
> 전략 다양화 설계서: [나이트메어 혼합 타워 유도 밸런스 설계](./superpowers/specs/2026-07-24-nightmare-mixed-tower-balance-design.md)
>
> 후반 난도 설계서: [나이트메어 N3~N6 난도 곡선 재조정 설계](./superpowers/specs/2026-07-24-nightmare-n3-n6-rebalance-design.md)

- [x] N1~N6 첫 3웨이브 슬라임 물량과 골렘 속도를 높이되 골드·점수를 보전해 슬로우 혼합 전략 유도
- [ ] 배포 후 화살-only 1별 가능 여부와 슬로우 혼합 구성의 2~3별 안정성을 실제 플레이로 확인
- [x] N1~N6 첫 3웨이브의 그림자 슬라임 수와 분열체 체력을 낮추고 초반 골드·전투 점수 보전
- [x] 나이트메어 초반 슬라임이 화살 타워로 처치하기 지나치게 어렵지 않도록 난이도 조정
- [x] N1 난이도 완화 이후 N2부터 난도가 급격히 상승하지 않도록 나이트메어 2~6의 후속 난이도 곡선 조정
- [ ] 반복 도전으로도 클리어하기 어렵다는 플레이 피드백을 기준으로 N3~N6의 난도 급등 구간과 초·중반 웨이브를 재측정하고, 단계별 상승감은 유지하면서 클리어 가능한 수준으로 재조정
- [x] 모든 몬스터의 체력을 현재보다 20% 증가
- [x] 빠른 요정의 이동 속도를 현재보다 20% 증가
- [x] 녹색 오크의 이동 속도를 현재보다 15% 증가

- [x] `deferred-decisions.md`의 초기 MVP 수치를 현재 값과 대조해 `적용 완료`·`후속 검증`·`대체됨` 상태와 최신 변경 위치 기록
